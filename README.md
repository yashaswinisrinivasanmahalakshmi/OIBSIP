# TASK 1: CALCULATOR WEB APPLICATION
A simple and responsive calculator built using HTML, CSS, and JavaScript. This project performs basic arithmetic operations and provides a clean user interface inspired by modern calculator designs.

## Features
- Addition, Subtraction, Multiplication, and Division
- Percentage calculations
- Square Root (√) operation
- Positive/Negative (±) toggle
- Delete last entered character
- Clear entire calculation
- ANS button to reuse the previous result
- Decimal number support
- Responsive design for different screen sizes
- Keyboard support for faster calculations

## Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)

## Project Structure
```
Calculator/
│
├── calc.html
├── calc.css
├── calc.js
└── README.md
```

## To run the project
1. Download or clone the project files.
2. Ensure all files are in the same folder.
3. Open `index.html` in any modern web browser.
No additional installation or dependencies are required.

# TASK 3: TO DO WEBAPP
A modern, feature-rich to-do web application that helps users organize daily tasks with separate pending and completed sections, edit/delete capabilities, and automatic timestamp tracking for when tasks are added or completed.

## About the Project
The goal of this project was to build an intuitive task management system that goes beyond a basic to-do list. The app separates pending and completed tasks into distinct columns, allows users to edit or delete any task regardless of status, and automatically records timestamps for task creation and completion. The design focuses on clarity, ease of use, and a smooth user experience with persistent local storage.

## Features
- Add new tasks with optional notes/details
- Two-column layout: Pending Tasks and Completed Tasks
- Mark tasks as complete (moves to Completed Tasks section)
- Revert completed tasks back to pending status
- Edit task titles and details at any time
- Automatic timestamps for task creation and completion
- Edit timestamps track when a task was last modified

## Technologies Used

- HTML5
- CSS3 
- JavaScript
- Local Storage API for data persistence

## Project Structure
```
├── todo2.html
├── todo2.css
├── todo2.js
└── README.md
```

## How to Run the Project
1. Download all three files (`index.html`, `style.css`, `script.js`).
2. Keep all files in the same folder.
3. Open `index.html` in any modern web browser.
4. Start adding tasks immediately — no installation or backend required.




# Task 4: LOGIN AUTHENTICATION SYSTEM
This is a simple login authentication web application that allows users to register, login, and access a secured page. The project demonstrates basic client-side authentication using HTML, CSS, and JavaScript.

## About the Project
The goal of this project was to create a beginner-friendly authentication system that simulates user registration and login functionality. User credentials are stored locally using the browser's local storage, and access to a protected page is restricted to authenticated users.

## Features
* User Registration
* User Login Authentication
* Protected/Secured Page Access
* Logout Functionality
* Client-side Data Storage using Local Storage
* Responsive and Clean User Interface
* Simple Form Validation

## Technologies Used
* HTML5
* CSS3
* JavaScript 
* Local Storage API

## Project Structure
```
├── Login.html
├── secure.html
├── login.css
├── login.js
└── README.md
```

## To Run the Project
1. Download all project files.
2. Keep the HTML, CSS, and JavaScript files in the same folder.
3. Open `index.html` in any web browser.
4. Register a new account using an email and password.
5. Login with the registered credentials.
6. Upon successful authentication, you will be redirected to the secured page.
7. Use the Logout button to end the session and return to the login page.
